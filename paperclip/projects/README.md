# projects

Project chart — one folder per Paperclip project (`projectId`).

- `{project-id}.md` — project title, linked goals (`goalId`), and a one-line
  description of what the project is driving.

Example: `e36e00f3-4e32-47ae-8d2d-69821311fe8e.md` is the project that groups
the current Graphos dev-cell work.
