# 16. Agent Scaffolding

## Overview

`graphos init --agents` scaffolds AI agent integration files (skills and sub-agents) so that AI tools like opencode and Claude Code can immediately query the knowledge graph.

## Usage

```bash
# Generate only graphos.yaml (existing behavior)
graphos init

# Scaffold agent files, auto-detecting targets from .opencode/ and .claude/ dirs
graphos init --agents auto

# Scaffold specific targets
graphos init --agents opencode
graphos init --agents opencode,claude
graphos init --agents generic
```

## Targets

| Target   | Files created |
|----------|--------------|
| opencode | `.opencode/skills/graphos/SKILL.md`, `.opencode/agent/graphos-navigator.md` |
| claude   | `.claude/skills/graphos/SKILL.md`, `.claude/agents/graphos-navigator.md` |
| generic  | `.agents/graphos.md` |

## Auto-detection

When `--agents auto` is used:
- If `.opencode/` exists → includes opencode target
- If `.claude/` exists → includes claude target
- If neither exists → includes all three targets

## Idempotency

Existing files are never overwritten. Each existing file is skipped with a message. The command exits successfully regardless of skips.

## Generated files

All generated files start with a stamp: `generated by graphos <version>`. This allows future tooling to identify scaffolds it owns.

### Skill files

The skill file (SKILL.md) teaches the primary agent:
- When to use `graphos query` vs grep
- The decision flow for query/path/explain/symbols/neighbors
- How to keep the graph fresh with `--update` and `ingest`
- A command reference rendered from the actual CLI parser (always up-to-date)

### Sub-agent files

The sub-agent (navigator) file:
- Restricts bash to `graphos *` commands only
- Denies write/edit tools
- Permits `graphos . --update`, `graphos .`, and `graphos ingest`
- Prefers `--update` and `--no-viz` for refreshes
