## 0. Unified Notation (single glossary)

Both source docs already share this glossary (sourced from the Graphos domain types); it is reproduced once here for the consolidated layer. Source-of-truth line numbers are taken from the committed expert docs and verified against the checked-in sources.

- `Node = Node { nodeId, nodeLabel, nodeFileType, nodeSourceFile, nodeLineStart, nodeLineEnd, nodeSignature, nodeCommunityId :: Maybe Int, nodeKind, nodeDegree :: Maybe Int, nodeIsBridge :: Maybe Bool, nodeExtra :: Maybe Value, nodePresentBits :: Word64 }` (`Node.hs:120`). `nodeFileType ∈ {CodeFile, DocFile, PaperFile, ImageFile, VideoFile, AudioFile, OfficeFile}`.
- `Edge = Edge { edgeId :: EdgeId, edgeSource :: NodeId, edgeTarget :: NodeId, edgeRelation :: Relation, edgeWeight :: Double, edgeConfidence :: Confidence Double, edgeExtra :: Maybe Value }` (`Edge.hs:88`). `edgeId = EdgeId (source "->" target ":" relationToText relation)` (`lsp-edge-extraction`). `Relation ∈ {Calls, Imports, Extends, Implements, References, Contains, DependsOn, Inferred}` (`Edge.hs:33`). `Confidence = Confidence Double` (`Edge.hs:77`).
- `Extraction = Extraction { extractionNodes :: Map NodeId Node, extractionEdges :: Map EdgeId Edge }`, accessors `extNodes / extEdges` (`Types/Graph.hs:47,66-69`). `emptyExtraction` (`Types/Graph.hs:54`) is the initial view.
- `LabeledGraph = LabeledGraph { gNodes, gEdges, gAdjFwd, gAdjBack }` (`Types/Graph.hs:83`). `Graph = Graph { gNodes, gEdges, gAdjFwd, gAdjBack, gDirected, gCompositions, gHash, gEmbeddings, gEmbeddingsPath }` (`Graph/Core.hs:47`).
- `neighbors g nid` / `degree g nid` (`Graph/Query.hs:37,44`): forward-only if `gDirected g`, else `gAdjFwd ∪ gAdjBack`; returns a `Set NodeId` (multi-edges collapse).
- `CommunityId = Int`; `CommunityMap = Map CommunityId [NodeId]`; `CohesionMap = Map CommunityId Double` (`Types/Graph.hs:43-45`).
- `Resolution = Resolution { resGamma :: Double, resMinSize :: Int, resMergeInto :: MergeStrategy, resMaxIterations :: Int }`; `MergeStrategy ∈ {MergeToNeighbor, MergeToLargest}` (`Community.hs:50-55`).
- Weighted context graph `G = (V, E, src, tgt, rel, w)`, `V = Map.keys (gNodes g)` (|V| = N), `E = Map.keys (gEdges g)`, `w = edgeWeight`. **Simple support graph** `G_s = (V, A)`, `{u,v} ∈ A ⟺ v ∈ neighbors(u) ∨ u ∈ neighbors(v)` (|E_s| = edges of G_s).
- `m = |E_s| = (Σ_v deg_s(v)) / 2`.

**Scope statement (critical, carries across both domains).** The Leiden scoring in `Domain.Community` runs on the **simple, unweighted support graph** `G_s`: `neighbors` returns a `Set`, `degree` counts distinct neighbors, and `edgeWeight` / `edgeRelation` are **not** read by `bestCommunityFor` or `localMovingLoop`. Every modularity claim is a claim about `G_s`; weighted-modularity requirements are explicitly out-of-scope for Leiden unless [AVI-508](/AVI/issues/AVI-508) reassigns them.

## 2. Proven Claims (theorems + invariants) with acceptance tests

**P-1 (Thm 2.1, GT-R4).** In one local-moving pass every accepted move `i: c→d` strictly increases `Q_γ`; `ΔQ = (k_{i,d} − γσ_tot(d)k_i/2m)/(2m) − (k_{i,c} − γσ_tot(c)k_i/2m)/(2m)`, and code `deltaQ(target) = sigmaIn/m − γ·(sigmaTot·ki)/(2m²)` equals `2·ΔQ` (identical up to positive factor 2), so `sign(deltaQ)=sign(ΔQ)` and the move is accepted iff `bestScore > 0`. ⇒ `Q_γ` strictly increases on each accepted move; INV-2 holds per pass.

**P-2 (Termination, GT-R6).** Loop counter decremented each iteration with base case returning immediately; full-cycle count ≤ `maxIter`. Within a pass, accepted moves strictly increase `Q_γ` over a finite value set ⇒ finite accepted moves per pass ⇒ each pass terminates ⇒ total bounded by `maxIter` (INV-3).

**P-3 (Functor axioms, CT-R4).** `F_d(id_V)=id`; `F_d(ψ∘φ)=F_d(ψ)∘F_d(φ)` reduces to three coordinate-wise equalities on nodes/edges/adjacency; dangling-edge stability closes the argument (a dangling edge stays dangling under any embedding, so `buildGraph`'s filter commutes with every embedding).

**P-4 (Colimit = coequalizer of coproduct, CT-R2/CT-R5/CT-R8).** Union realizes both the n-way colimit and the dedup coequalizer (`|keys colim| = |⋃ keys|`, each key once); pushout is the colimit over the span category. Universal property fixes the object up to unique iso and the mediating morphism uniquely.

**P-5 (INV-1/4/5/6, GT-R2/8/9).** Disjoint cover; merge preserves membership union; cohesion ∈ [0,1] (given A1); assignment is a total function `V → C`.

**P-6 (Complexity, GT-R7 / CT-R12).** Per-phase table in the graph doc; total `O(maxIter·(E_s+N))`, memory `O(N+C+E_s)`, n-way colimit `O(Σ|Vᵢ|)` single left-fold.

**P-W1 (workflow precedence is a strict partial order when acyclic, GT-W1).** `⨁ = E_ord⁺` is transitive by definition (`⨁ = ⋃_{k≥1} E_ord^k`). It is irreflexive iff `(V, E_ord)` contains no directed cycle through any vertex, equivalently iff every SCC of `(V, E_ord)` is a singleton, equivalently iff `(V, E_ord)` is acyclic. When acyclic, `cond(G|Rel_ord)` has all-singleton SCCs and coincides with `(V, E_ord)` up to transitive reduction; any topological sort of `cond(G|Rel_ord)` is a linear extension of `⨁` and vice-versa. **Proof sketch (irreflexivity ⇀ acyclicity).** `u ⨁ u` iff ∃ k≥1 and an `E_ord`-walk `u → … → u`, i.e. a directed cycle through `u`; this holds for some `u` iff `(V,E_ord)` has any directed cycle iff some SCC of `(V,E_ord)` is non-singleton. **Proof sketch (topo exists).** A finite DAG admits a topological order (Kahn); `cond(G|Rel_ord)` is a DAG by the AVI-518 Thm 2.3 argument (a cycle among distinct condensation nodes would make their representatives mutually `E_ord`-reachable, contradicting SCC distinctness). ⇒ INV-W1 (`⨁` irreflexive+transitive) ⇔ `(V,E_ord)` acyclic; a topological sort exists when acyclic, and `cond(G|Rel_ord)` is always a DAG quotient used when recursion/circular imports force non-singleton SCCs.

**P-W2 (condensation + topo order are linear, GT-W1 / GT-W4).** Computing `cond(G|Rel_ord)` = Tarjan SCCs of `(V,E_ord)` (`O(V+E)`) plus Kahn topological order of the condensation (`O(V+E)`); total `O(V+E)`, degrading to `O((V+E)·log N)` only if adjacency is read via `Data.Map`/`Data.Set` rather than FGL CSR (`Analysis.hs:4`). **Termination.** Tarjan is a single iterative DFS pass whose discovery index strictly decreases and is bounded below by 0 (AVI-518 Thm 2.2 / INV-9); each arc is inspected a constant number of times. Kahn decrements in-degree; each arc is inspected once. Both are bounded by `O(V+E)` ⇒ GT-W4 holds for precedence extraction and topological ordering.

**P-W3 (canonical trace = hop distance over `E_ord`; representation-independent, GT-W2).** For `s,t` with `s →*_W t` (s reaches t via `⨁`, equivalently via `E_ord`), the canonical trace is the hop-minimal directed walk of length `d(s,t)`, computed by BFS over `(V, E_ord)`; it exists iff `s →*_W t` (AVI-518 Thm 2.4). **Representation-independence (INV-W3).** `toCachedFGL` keys nodes in ascending `NodeId` order (`Map.toList`, `Analysis.hs:66`) and edges in ascending `EdgeId` order (`Map.elems`, `Analysis.hs:78`); `Data.Map.Strict` normalizes storage order independent of insertion, so two graphs with identical `(V,E_ord)` sets yield identical FGL adjacency and hence identical BFS/ESP node sequences. ⇒ Determinism: same `W` under two insertion orders ⇒ identical trace.

**P-W4 (phase layering is linear and intra-phase-back-edge-free, GT-W3).** Longest-path layering of `cond(G)` restricted to community supernodes: contract each community to a supernode in the DAG `cond(G)` (`O(V_c + E_c)`), then assign `layer(C)` = longest path length from a source supernode in topological (Kahn) order (`O(V_c + E_c)`); total `O(V_c + E_c)` with `V_c = #communities`, `E_c = #inter-community arcs in cond(G) ≤ E`. **Invariant INV-W4.** For every inter-community arc `(C₁, C₂)`, `layer(C₂) ≥ layer(C₁) + 1 > layer(C₁)` (longest-path layering guarantee), so no arc joins two communities in the same phase (equal layer) and no arc runs backward. **Termination.** Single topological pass over the DAG `cond(G)`; strictly bounded. ⇒ GT-W4 bound holds for layering.

**P-W5 (workflow-order functor + natural iso, CT-W1).** `order : Graph → Preord`, `order(G) = (V, ⨁_G)` with `u ⨁_G v ⟺ ∃ E_ord-path u→…→v` (GT-W1). `order` is a functor: a structure-preserving map `g : G → H` (preserving src/tgt/relation/direction) preserves `E_ord` and their endpoints, so reachability in `G` maps into reachability in `H` ⇒ `order(g)` monotone; `order(id)=id`, `order(g∘h)=order(g)∘order(h)`. With `extract : FileSet → 𝔻` (AVI-524 §4.1) and `F_d : 𝔻 → Graph` (CT-R4), the pointwise natural transformation `α : order ∘ F_d ⇒ order_𝔻` has components `α_E : order(F_d E) ≅ order(E)` — building a view into a graph then reading its workflow order equals reading the view's order directly; each `α_E` is an iso of preorders. **Naturality on consistent families.** For a consistent `{Vᵢ}` with colimit cocone `{ιᵢ : Vᵢ → M}` (view-embeddings), applying `order` yields a cocone `{order(ιᵢ) : order(Vᵢ) → order(M)}`; this cocone is universal (isomorphic into `order(M)`) iff per-view orders agree on overlaps — the consistency condition of CT-R9/§3.1 — because then the legs cohere into a unique mediating monotone map. **Designated non-naturality witness.** Two views over shared symbols with conflicting relative order — `V₁` carries `x→y` (`rel ∈ Rel_ord`) and `V₂` carries `y→x` — make `order(V₁)` and `order(V₂)` disagree on `(x,y)`; the merged `order(M)` carries the 2-cycle `x↔y`, so `⨁_M` is reflexive at `x,y` and is a preorder that is **not** antisymmetric (no partial order). No unique mediating morphism exists, so the naturality square fails to commute on the nose — witnesses exactly the Q0b(a) boundary (order carried by structure only when per-view orders are consistent).

**P-W6 (colimit-of-orders = order-of-colimit, CT-W2).** For a consistent family `{Vᵢ}` with colimit `M = colim F_d` (pre-inference): merge preserves ordered edges and relations (CT-R9), so `E_ord(M) = ⋃ᵢ E_ord(Vᵢ)`; hence `order(M) = E_ord(M)⁺ = (⋃ᵢ E_ord(Vᵢ))⁺`. Transitive closure commutes with arbitrary union — `(⋃ₖ R_k)⁺ = (⋃ₖ R_k⁺)⁺` (each `R_k ⊆ ⋃R_k ⇒ R_k⁺ ⊆ (⋃R_k)⁺`, and dually) — so this equals `(⋃ᵢ E_ord(Vᵢ)⁺)⁺ = (⋃ᵢ ⨁_{Vᵢ})⁺`, the least preorder containing every local order. Thus `order(M) = ⨁ᵢ order(Vᵢ)` — colimit-of-orders ≅ order-of-colimit, mediating map unique up to unique iso. **Boundary = inference, not community detection.** The equality holds as long as `E_ord(M) = ⋃E_ord(Vᵢ)`; post-merge `inferEdges` (`UseCase/Infer.hs:304`) / `addEdges` may ADD a new ordered edge `x→y` absent from every view, so `E_ord(M') ≠ ⋃E_ord(Vᵢ)` and the equality breaks. This is exactly the Q0b(a) inference boundary pinned in §3 A5, and it does **not** rest on CT-R10 (community re-detection is about communities, not edges) — the two are explicitly non-conflated. Property-testable: consistent ordered fixture ⇒ `order(merge(Vᵢ)) == join(order(Vᵢ))`; a fixture where inference adds an edge between two previously-unordered components changes the merged order.

**P-W7 (pipeline functor preserves recovered order up to inference, CT-W3).** Model the structural core of `runPipelineBody` (`UseCase/Pipeline/Core.hs`) as a functor `P : 𝔻 → Graph`: stage 2 extract (`extractAll`) yields views in `𝔻`; stage 3 build (`buildGraphFromExtractions`) is `F_d` (CT-R4), identity+composition preserving; so `order ∘ P ≅ order_𝔻` on the structural legs (functor axiom on order: build-then-order = order-directly). **Inference leg.** `clusterGraph` (`UseCase/Pipeline/Core.hs:434-441`) runs `inferSemanticEdgesForMode`/`inferNonSemanticEdges` then `addEdges` (`Core.hs:170`) BEFORE re-clustering (step 5, CT-R10); `addEdges` can ADD edges whose relation ∈ `Rel_ord` (e.g. inferred `DependsOn`/`References`, GT-W1 gated by `edgeConfidence ≥ τ`). Under that leg `order` is preserved only up to the comparison "the inferred ordered edge was added" — a lax (directed) step, not a strict one — so full-pipeline order-preservation holds on the structural core and is Assumed pending confirmation that the inference leg's added ordered edges are the only source of order change (§3 A5, O-W2).
