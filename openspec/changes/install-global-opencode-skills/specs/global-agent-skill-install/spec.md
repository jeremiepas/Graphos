# Capability: global-agent-skill-install

## Purpose

Provide a dedicated CLI command to install Graphos skills into the user-level opencode skills directory, making them globally loadable by opencode across any workspace. Complements project-local `graphos init --agents` scaffolding.

## ADDED Requirements

### Requirement: New install-skill command
The CLI SHALL provide a top-level `install-skill` subcommand with a required `--target <TARGET>` option (PRD §13.1 extension). For `TARGET = opencode`, the command SHALL write user-level skill files under `~/.agents/skills/`. The command SHALL accept no other required arguments.

#### Scenario: Command exists and accepts target
- **WHEN** `graphos install-skill --target opencode` is invoked
- **THEN** the command resolves the user's home directory and attempts to install the opencode skills under `~/.agents/skills/`

#### Scenario: Missing target is rejected
- **WHEN** `graphos install-skill` is invoked without `--target`
- **THEN** the command exits with an error that names the missing option and no files are written

#### Scenario: Unknown target is rejected
- **WHEN** `graphos install-skill --target foo` is invoked
- **THEN** the command exits with an error listing the valid target(s) and no files are written

### Requirement: Global opencode skill pair
For target `opencode`, `install-skill` SHALL create exactly two files:
- `~/.agents/skills/graphos/SKILL.md` — full skill allowing graph query, maintenance (`--update`, `ingest`), and build operations.
- `~/.agents/skills/graphos-query/SKILL.md` — query-only skill allowing `query`, `path`, `explain`, `symbols`, and `neighbors`; the skill body SHALL explicitly forbid build, update, and ingest operations.

#### Scenario: Both global skills created
- **WHEN** `graphos install-skill --target opencode` is run and neither global skill exists
- **THEN** both `~/.agents/skills/graphos/SKILL.md` and `~/.agents/skills/graphos-query/SKILL.md` are created

#### Scenario: Query-only skill forbids maintenance
- **WHEN** `graphos-query` skill content is generated
- **THEN** its body contains an explicit statement that build, update, and ingest operations are not permitted

### Requirement: YAML frontmatter on all generated skills
Every generated skill file, including global skills and project-local skills created by `graphos init --agents`, MUST begin with a YAML frontmatter block containing `name` and `description` keys, followed immediately by the `generated by graphos <version>` stamp. The block SHALL use standard YAML delimiters `---` on its own lines.

#### Scenario: Global full skill frontmatter
- **WHEN** `~/.agents/skills/graphos/SKILL.md` is generated
- **THEN** its first lines are `---`, `name: graphos`, `description: ...`, `---`, then `generated by graphos <version>`

#### Scenario: Project-local skill frontmatter updated
- **WHEN** `graphos init --agents opencode` regenerates `.opencode/skills/graphos/SKILL.md`
- **THEN** the file begins with the same YAML frontmatter block followed by the version stamp

### Requirement: Idempotent global install
`install-skill` MUST be non-destructive: if either target skill file already exists, that file is skipped with a per-file message; the other file MUST still be written if absent, and the command MUST exit successfully. Existing files are left byte-identical.

#### Scenario: One file already exists
- **WHEN** `~/.agents/skills/graphos/SKILL.md` exists and `~/.agents/skills/graphos-query/SKILL.md` does not
- **THEN** running `graphos install-skill --target opencode` skips the existing file, creates the missing file, and exits 0

#### Scenario: Both files already exist
- **WHEN** both global skill files exist and `graphos install-skill --target opencode` is run
- **THEN** both files are skipped, a skip message names each, and the command exits 0

### Requirement: No global sub-agent generated
`install-skill` SHALL generate skill files only. It SHALL NOT create any agent/sub-agent definition under `~/.agents/agents/` or elsewhere, because opencode agent registry behavior is project-local.

#### Scenario: No agent files created
- **WHEN** `graphos install-skill --target opencode` is run
- **THEN** no files are created outside `~/.agents/skills/`

## MODIFIED Requirements

### Requirement: Version-stamped generated files
Every generated file MUST begin with a stamp identifying the generating tool and version (`generated by graphos <version>`), so future tooling can distinguish scaffolds it owns from user-authored files.

#### Scenario: Stamp follows frontmatter
- **WHEN** any scaffold skill file is generated
- **THEN** the version stamp appears immediately after the YAML frontmatter block

### Requirement: Pure scaffold planning
Scaffold planning (target set + relative paths + rendered contents) MUST be a pure function in Domain/UseCase returning a list of file plans; all filesystem effects (detection facts, existence checks, directory creation, writes, reporting) MUST live in Infrastructure (PRD §4, architecture-purity).

#### Scenario: Global install planning is pure
- **WHEN** the global opencode install planner is exercised with a fixed command reference
- **THEN** it yields deterministic file paths and contents matching golden files, with no filesystem access
